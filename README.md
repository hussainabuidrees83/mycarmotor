# معرض السيارات — Hugo

## التشغيل
    hugo server            # معاينة على http://localhost:1313
    hugo --minify          # بناء الموقع النهائي في مجلد public/

## النشر المجاني على GitHub Pages
الموقع منشور من المستودع `hussainabuidrees83/mycarmotor` على:
https://hussainabuidrees83.github.io/mycarmotor/

كل تحديث إلى فرع `main` يشغّل بناء Hugo ونشر الموقع تلقائياً عبر GitHub Actions.

## تعديل رقمك
افتح `hugo.toml` وغيّر `phone` و `whatsapp` (واتساب بصيغة دولية بدون + مثل 97333123456).

## إضافة سيارة
1. أنشئ مجلداً باسم ملف السيارة داخل `static/images/cars/` وضع فيه الصور الحقيقية (بصيغة JPG بعرض 1600px تقريباً)، مثال: `static/images/cars/mg-hs-1-5t-lux-2027/` — تُعرض تلقائياً بترتيب أسماء الملفات (1.jpg ثم 2.jpg…) وأول صورة هي صورة الغلاف. وإذا لم تتوفر صور حقيقية تظهر صورة موحدة تفيد بأن الصورة غير متوفرة حالياً.
2. انسخ ملف سيارة من `content/cars/` باللغتين (`.ar.md` و `.en.md` بنفس الاسم الأساسي).
3. عدّل البيانات. الحقول الاختيارية (freeService, tint, undercoat, monthly, mileage) تُحذف إن لم تنطبق.
   `condition` إما new أو used. `weight` لترتيب العرض.

لإخفاء سيارة (مباعة): أضف `draft: true` في أعلى الملف.

## الصور (الطريقة الأسهل)
لكل سيارة مجلد جاهز داخل `static/images/cars/` باسم السيارة، فقط ضع صور السيارة داخله وستظهر كلها تلقائياً في صفحتها (بالعربية والإنجليزية معاً) بترتيب أسماء الملفات، وأول صورة هي صورة الغلاف.
- لتغيير مجلد سيارة معينة أضف في أعلى ملفها السطر: `imagesFolder: "اسم-المجلد"`.

إذا لم تتوفر صورة حقيقية للسيارة، يعرض الموقع الصورة البديلة الموحدة تلقائياً إلى أن تُضاف الصور.
